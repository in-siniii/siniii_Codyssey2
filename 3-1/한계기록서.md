## [한계 1] 조건에 맞는 알림 문구만 골라 한 메시지로 모으기

| 항목 | 내용 |
|---|---|
| 하려던 기능 | 비 / 추위 / 일교차 중 해당하는 알림 문구만 골라서, 텔레그램 메시지 하나에 모아 보내기 |
| 사용한 도구 | Activepieces (Make에서는 메시지 칸의 `if()` 수식으로 구현됨) |

**막힌 이유 (직접 작성)**

Activepieces에서 해당하는 조건의 메시지를 하나로 모아 전송할 수 있도록 수식을 찾아보았으나, 없었음.
Make처럼 if라는 수식이 있어야 해당하는 조건이 여러 개일 때 하나로 담아서 전송할 수 있지만, Activepieces에는 if 조건 수식이 존재하지 않아 하나로 담아서 보낼 수 없고, 여러 개의 메시지로 나눠지는 상황이 발생함.

## [한계 2] AI가 정해 준 분류 기준을 항상 지키게 하기

| 항목 | 내용 |
|---|---|
| 하려던 기능 | AI 블록이 프롬프트에 적은 분류 기준(비 / 추움 / 쾌적)대로만 날씨를 분류하게 하기 |
| 사용한 도구 | Make (Make AI Toolkit - Simple Text Prompt) |
| 겪은 일 | 쾌적 경로를 테스트하려고 비 기준을 60% → 90%로 바꿨지만, 비 올 확률 77%에서도 AI가 "비"로 분류함. 결국 기준대로 분류하게 만들지 못하고, 날씨 값을 테스트용 숫자로 바꿔서 다른 경로를 테스트함 |

**막힌 이유 (직접 작성)**

프롬프트의 비 기준을 90% 이상으로 바꿔서 실행해 보았지만, 비 올 확률이 77%인데도 "비"로 분류되었다. 원인을 몰라서 찾아보니, AI가 프롬프트에 적어 준 기준보다 자기 판단을 따른 것 같았다.

## [한계 3] 원하는 지역의 날씨 받기

| 항목 | 내용 |
|---|---|
| 하려던 기능 | 텔레그램으로 지역 이름을 보내면 그 지역의 날씨와 옷차림 추천을 받기 |
| 사용한 도구 | Make (HTTP - Open-Meteo) |
| 겪은 일 | 프로젝트 1을 설계할 때 여러 지역을 고려했지만, 서울 강남구 한 곳의 좌표(위도 37.5172, 경도 127.0473)를 주소에 고정해서 만듦. 고려했다가 포기한 기능 |

**막힌 이유 (직접 작성)**

한 지역만 정해서 보기보다는 원하는 다른 지역의 날씨도 볼 수 있게 하고 싶었다. 하지만 날씨 서비스가 지역 이름이 아니라 좌표로만 날씨를 주기 때문에, 지역 이름을 좌표로 바꾸는 단계가 필요했다. 주어진 시간 안에 이 기능까지 만들기는 어려울 것 같아서 과감하게 포기했다.

## 🔧 코드 시도 기록

**대상:** [한계 1] 조건에 맞는 알림 문구만 골라 한 메시지로 모으기

### 1. AI에게 요청한 내용

```
Activepieces Code 블록에 넣을 코드를 만들어줘.
최고 기온, 최저 기온, 비 올 확률을 받아서
비 올 확률이 60% 이상이면 "☔ 비가 올 수 있어요, 우산 챙기세요",
최저 기온이 0도 이하면 "🧣 많이 추워요, 따뜻하게 입으세요",
일교차가 10도 이상이면 "🧥 일교차가 커요, 겉옷 챙기세요"
문구를 넣고, 해당하는 문구만 모아서 텔레그램으로 보낼 메시지 하나를 만들어줘.
메시지 첫 줄에는 "🌤 오늘 강남구 날씨 (최저 ○° / 최고 ○°)"가 들어가야 해.
```

### 2. 받은 코드

언어: JavaScript (Activepieces Code 블록에서 쓰는 언어)

```javascript
export const code = async (inputs) => {
  // 1. 날씨 값을 숫자로 바꾸기
  const max = Number(inputs.max);   // 최고 기온
  const min = Number(inputs.min);   // 최저 기온
  const rain = Number(inputs.rain); // 비 올 확률

  // 2. 일교차 계산 (소수 한 자리로 맞추기)
  const range = Math.round((max - min) * 10) / 10;

  // 3. 첫 줄 만들기
  const lines = [`🌤 오늘 강남구 날씨 (최저 ${min}° / 최고 ${max}°)`];

  // 4. 조건에 맞는 문구만 추가하기
  if (rain >= 60) lines.push("☔ 비가 올 수 있어요, 우산 챙기세요");
  if (min <= 0) lines.push("🧣 많이 추워요, 따뜻하게 입으세요");
  if (range >= 10) lines.push("🧥 일교차가 커요, 겉옷 챙기세요");

  // 5. 줄바꿈으로 이어서 메시지 하나로 만들기
  return { message: lines.join("\n") };
};
```

### 3. 코드를 넣은 위치

- 도구: Activepieces
- 위치: Router의 Branch 1 안, 텔레그램 블록 **바로 앞**에 Code 블록을 추가함
- Inputs: `max`, `min`, `rain` 3개를 만들고 각각 HTTP 블록의 최고 기온, 최저 기온, 비 올 확률 0번 값과 연결함
- 텔레그램 블록의 Message 칸에는 Code 블록 결과의 `message`를 넣음

![코드를 넣은 화면](images/코드_위치.png)

**내가 판단한 내용 (직접 작성)**

Make와 달리 Activepieces에서는 왜 이 기능이 안 되는지 잘 이해가 되지 않아, AI를 활용해 그 이유를 알아보았다. 원인을 파악하고 나니 코드를 직접 넣으면 해결할 수 있다는 것을 알게 되었고, 어떤 코드가 필요한지도 알 수 있었다.
이번 시도로 노코드 도구에서 막히는 문제가 생겼을 때 코드로 해결할 수 있다는 것을 알게 되었다. 앞으로는 문제가 생기면 원인을 파악하고 원리를 이해하는 데에도 힘써야겠다고 생각했다.
