## 1. 자동화 대상 업무 정의

**[자유 주제] 옷차림 비서: 텔레그램으로 "날씨"를 보내면 AI가 오늘 날씨에 맞는 옷차림을 알려 주기**

매일 나가기 전에 날씨 앱을 열어 기온과 비 소식을 확인하고, 무엇을 입을지 고민하는 일을 자동화한다. 텔레그램 봇에 "날씨"라고 보내면 서울 강남구의 오늘 날씨를 가져와 AI가 "비 / 추움 / 쾌적" 중 하나로 분류하고 옷차림을 추천하며, 분류에 따라 다른 안내 문구와 함께 텔레그램으로 보내 준다.

- 처리 대상: 날씨 공개 정보(Open-Meteo)와 테스트용 텔레그램 메시지 "날씨" (실제 업무 데이터나 개인정보는 사용하지 않음)
- 프로젝트 1에서 만든 "아침 날씨 알림"을 더 발전시킨 주제

## 3. 워크플로우 설계

### 3-1. 전체 흐름

```
[트리거] 텔레그램 봇에 메시지가 오면 바로 실행 (Telegram Bot - Watch Updates)
   ↓
[액션 1] 오늘 강남구 날씨 가져오기 (HTTP - Make a request, Open-Meteo)
   ↓
[액션 2 - 생성형 AI] 날씨를 보고 분류와 옷차림 추천 만들기 (Make AI Toolkit - Simple Text Prompt)
   ↓
[조건 분기] AI 분류 결과로 길 나누기 (Router)
   ├─ 비   → [액션 3] ☔ 비 안내 + AI 추천을 텔레그램으로 보내기
   ├─ 추움 → [액션 4] 🧣 추위 안내 + AI 추천을 텔레그램으로 보내기
   └─ 쾌적 → [액션 5] 🌤 쾌적 안내 + AI 추천을 텔레그램으로 보내기
```

### 3-2. 단계별 설명

| 구분 | 블록 | 내용 |
|---|---|---|
| 트리거 (시작 조건) | Telegram Bot - Watch Updates (1번) | 텔레그램 봇에 메시지가 도착하면 즉시(Instant) 실행됨. 시나리오를 켜 두면 사람이 따로 실행하지 않아도 자동으로 돌아감 |
| 액션 1 | HTTP - Make a request (2번) | Open-Meteo에서 서울 강남구의 오늘 최고 기온, 최저 기온, 비 올 확률을 가져옴 |
| 액션 2 (생성형 AI) | Make AI Toolkit - Simple Text Prompt (3번) | 날씨 값 3개를 프롬프트에 넣어 AI가 "분류: (비/추움/쾌적)"와 "추천: (옷차림 두 문장)"을 만듦 |
| 조건 분기 | Router (5번) | AI가 만든 답(Answer)을 보고 세 길 중 하나로 보냄 |
| 분기 기준 | 각 길의 필터 | AI 답에 `분류: 비` / `분류: 추움` / `분류: 쾌적` 글자가 **들어 있는지**(Text operators: Contains)로 나눔 |
| 액션 3 (비 경로) | Telegram Bot - Send a Text Message or a Reply (6번) | "☔ [비] 오늘 강남구에 비 소식이 있어요. 우산 챙기세요!" + AI 답 |
| 액션 4 (추움 경로) | Telegram Bot - Send a Text Message or a Reply | "🧣 [추움] 오늘 강남구는 많이 추워요. 따뜻하게 입으세요!" + AI 답 |
| 액션 5 (쾌적 경로) | Telegram Bot - Send a Text Message or a Reply | "🌤 [쾌적] 오늘 강남구 날씨는 괜찮아요." + AI 답 |

**AI 분류 기준 (프롬프트에 적은 기준)**

| 분류 | 기준 |
|---|---|
| 비 | 비 올 확률이 60% 이상 |
| 추움 | 비가 아니고, 최저 기온이 5도 이하 |
| 쾌적 | 그 외 |

### 3-3. 생성형 AI 액션에 넣은 프롬프트

```
너는 날씨에 맞춰 옷차림을 추천하는 비서야.

오늘 서울 강남구 날씨:
- 최고 기온: {{first(2.data.daily.temperature_2m_max)}}°
- 최저 기온: {{first(2.data.daily.temperature_2m_min)}}°
- 비 올 확률: {{first(2.data.daily.precipitation_probability_max)}}%

아래 형식으로만 답해.
분류: (비, 추움, 쾌적 중 하나)
추천: (옷차림 추천 두 문장)

분류 기준:
- 비 올 확률이 60% 이상이면 "비"
- 비가 아니고 최저 기온이 5도 이하면 "추움"
- 그 외에는 "쾌적"
```
